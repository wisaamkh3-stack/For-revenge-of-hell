# ثأر الجحيم

لعبة بقاء 2D بيكسل ارت من الأعلى بأسلوب دوم. ملف HTML واحد بدون مكتبات.

## التشغيل
افتح `index.html` في المتصفح. ما تحتاج تثبيت شيء.

## النشر على GitHub Pages
1. ارفع `index.html` و `README.md` إلى مستودع جديد.
2. من Settings ثم Pages اختر الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/اسم-المستودع/`

## التحكم
- الجوال: اسحب باليسار للحركة وباليمين للتصويب والإطلاق، ويشتغل بالوضع الأفقي.
- الكمبيوتر: WASD للحركة، الماوس للتصويب، النقر للإطلاق، 1 إلى 5 لتبديل السلاح، P للإيقاف.

## اللعبة
- قصة انتقام: رعد يثأر لأبيه أو لأمه من زاغور.
- أسلحة وعلاج يظهرون عشوائيًا في الماب.
- شياطين صغيرة بدون وجوه.
- سلاح ملاحق ضعيف، وقصف عشوائي ضرره عالي.
- قدرات دائمة، وكل قدرة ترفع غضب الجحيم فيكثر الأعداء ويقوون.
